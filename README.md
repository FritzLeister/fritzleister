Landing Page hat 2 Buttons:
    "Gespeichert": Wenn es gespeicherte Hallen gibt, dann werden die dort angezeigt
    "Los Geht!": Kleine Conversation für die Eckdaten der Halle

"Gespeichert":
    Kann bis hin zu 8 Hallen anzeigen (mehr sieht einfach nicht so gut aus)
    Pfeil oben links --> Landing Page

    Jede gespeicherteHalle:
        "Stift": Name kann bearbeitet werden
        "Extend": Konfiguration öffnen
        "Einbahnstraße": Löschen der Halle

"Los Gehts":
    Man kann mit den Pfeilen hin und her "swappen" oder auch über die Buttons links
    Konfiguration Abschließen auf der 4. Page

Im Konfigurator:
    Durch Drehen des Modells kann sich jede Seite der Halle angesehen werden
    Weite Objekte können durch das blaue Mui-SpeedDial hinzugefügt werden

    Zur Navbar:
        "Save" Button:
            Speichert Halle zusammen mit den Objekten, wie zB Türen usw
        "Home" Button:
            Bringt Benutzer zur Landing Page zurück (Konfiguration ist wieder Zurückgesetzt)
        "Reset" Button:
            Bringt den Benutzer wieder zur Conversation und Objekte werden gelöscht
